# Условный паркинг 60 × 30 м

Синтетический образец для сквозного прогона и демонстрации выпуска томами (АУПТ и АПС): чертёж `floor.dxf` создан
скриптом (ezdxf) по соглашению о слоях README §7 — контур с именем, колонны, две балки высотой 500 мм, ввод, насосная
12 × 8 м с двумя вводами, выпуском и патрубками; `sample.waproj` — проект с разделом `alarm` (дымовые ДИП-34А-03,
алгоритм C, ИПР 513-3АМ, точка поста, СОУЭ, вентиляция); `floor_m2.dxf` — второй уровень (−2 этаж, отм. −6,000: та же
стоянка без насосной, ezdxf) для раздела `alarm.levels`; 90 машино-мест → речевое оповещение (табл. Б.1), фон 60 дБА задан проектировщиком вместо 70 по табл. В.1 (вопрос А-16) — лист плана АПС на каждый уровень, стояки в кабельном журнале.
Не документация заказчика. Запуск:

```bash
dotnet run --project src/WaterAuto.Cli -- calc tests/Samples/parking60x30/sample.waproj --out out/parking60x30 --data data
```
