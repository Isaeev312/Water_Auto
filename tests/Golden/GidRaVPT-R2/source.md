**Как считает ГидРаВПТ (установлено пересчётом всего отчёта; совпадение до последнего напечатанного знака).**
- q = 10K√P; ΔP = Q²L/(100·Kт); выравнивание ветвей по Б.21 с учётом отметки ветви: Q испр = Q усл·√((P узла − ΔZ/100)/(P усл − ΔZ/100)).
- Участок «кольцевой» считается на Q/2 (потери и скорость); второе полукольцо не моделируется.
- **Множитель 1/0,95² = 1,10803** на потерях (и 1/0,95 на скорости) всех труб сети — ветвей, питающих, подводящих; нет его только на трубах ПК, в q оросителей, в Q секции, в УУ и в диаметре всасывающей трубы. Численно это расчёт труб на расход Q/0,95. Смысла отчёт не объясняет (open_questions.md, В-05).
- ПК — эмиттер при фактическом давлении: q = 2,6·√(P/0,1); потери в трубе ПК — при фактическом расходе. Выведенное в таблице «p уч.» 0,001252 — потери при нормативных 2,6 л/с, в расчёт не входят.
- P_уу = ξ·9,80665·Q², Q в м³/ч, результат в МПа.
- **20 % местных потерь — дважды:** P секции = P(УУ) + P_уу + 0,2·Σ потерь труб диктующего пути (ветвь 1 + 1.1…9.1, без УУ) = 0,382708 + 0,015388 + 0,034742 = 0,432837; затем к давлению после подводящих (0,443350) ещё 0,2·Σ потерь подводящих = 0,002103 → 0,445453.
- Насос: 0,445453 + (1,50 − 1,0)/100 − 0,437 = 0,013453 МПа. Перевод в метры в отчёте непоследователен (×101,97 для насоса, ×100 для жокея), поэтому «м вод. ст.» не сравниваются.
