# GidRaVPT-R2-plain — та же секция без множителя

**Источник.** Файл проекта ГидРаВПТ `07_Эталонные_примеры/Расчет1.2.hvd` (у заказчика, в репозиторий не кладётся). Строки в UTF-32LE; шесть секций, каждая содержит дамп таблицы-листа в UTF-16LE со входными данными и сохранёнными результатами (в столбцах 8–9 — неокруглённые значения). Секция 4 файла по входным данным совпадает с отчётом R2 (см. `../GidRaVPT-R2/source.md`), но её сохранённые результаты посчитаны **без множителя 1/0,95²**: видимо, файл сохранён до обновления программы (PDF назван «после обновления»). Версия программы в файле не записана.

**Вход.** Тот же `input.waproj`, что у R2, без `compat.pipeFlowDivisor`.

**Ожидаемые значения (из файла).** Q секции 50,5742 л/с; P_уу 0,015049618…; P в конце 9.1 0,364108; ΔP ветви 1: 0,008536 / 0,032346 / 0,066436; расходы ветвей 2–6 после выравнивания 7,029 / 6,604 / 7,033 / 6,620 / 7,060; ПК-6 0,356 МПа / 4,902 л/с, ПК-7 0,363 / 4,955; подводящие 0,414819 / 0,419458.
- P секции 0,410179 в файле не хранится — выведено: давление в конце подводящего 1 (0,414819) минус его потери (0,004640). Та же формула, что в R2, воспроизводит его до 10⁻⁶.
- Давление насоса по той же формуле вышло бы отрицательным (−0,0107: подпор больше требуемого) — в файле его нет, в тест не включено.

**Статус `compat`.** Тест не требует необъяснённого множителя, но проверяет правила ГидРаВПТ: кольцевой участок на Q/2, 20 % от потерь диктующего пути, ПК при фактическом давлении. Расчёт по СП 485 в программе (солвер + нормативный вариант 50/100 %) даст другие числа.

**Проверка.** Независимым решателем воспроизведены все 23 величины.
