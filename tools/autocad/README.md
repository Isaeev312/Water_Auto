# AutoLISP для Water_Auto

`wa.lsp` — команды AutoCAD для подготовки чертежа и вставки результатов. Лицензия MIT, как у репозитория.

**Не проверено в AutoCAD** — проверьте на копии чертежа и сообщите об ошибках.

## Установка

AutoCAD 2021 и новее: файл в UTF-8, нужна системная переменная `LISPSYS` = 1 (по умолчанию в новых версиях). Загрузка — `APPLOAD` → `wa.lsp`, или добавить в «Автозагрузку».

## Команды

| Команда | Что делает |
|---|---|
| `WA-SETUP` | Создаёт слои соглашения (`ПТ_КОНТУР`, `ПТ_КОЛОННЫ`, `ПТ_БАЛКИ`, `ПТ_КОРОБА`, `ПТ_ЗАПРЕТ`, `ПТ_ВВОД`, `ПТ_НС`, `ПТ_ОТМЕТКИ` и др.) и выхода программы с цветами как в DXF программы; единицы чертежа — мм. |
| `WA-CHECK` | Проверка перед расчётом: незамкнутые полилинии, объекты, которые программа не читает, балки без толщины (высоты), нет `ПТ_ВВОД`, единицы не мм. Пометки — кружки и текст на слое `ПТ_ПРОВЕРКА` (при повторном запуске стираются). Самопересечения, вложенность и положение объектов проверяет импорт программы. |
| `WA-INSERT` | Вставляет DWG, выданный программой (`PlanDxfWriter.Write` с расширением `.dwg`), в 0,0 с расчленением: объекты ложатся на свои слои. По запросу сначала удаляет прежние объекты слоёв выхода. ID оросителей — скрытый атрибут (`ATTDISP` = Вкл.). |

Чисел норм в LISP нет: проверки по СП 485 выполняет программа.

## Полезные сторонние программы (ставить самостоятельно)

Программы Lee Mac бесплатны для личного использования, но по их условиям (lee-mac.com/terms.html) не распространяются в составе чужих программ — поэтому в репозитории их нет:

- NumInc — нумерация (марки оросителей на отдельном видимом тексте; скрытый атрибут ID не перезаписывать);
- Total Length & Area (`tlen`) — сверка длин труб слоя `ПТ_ТРУБЫ` с ведомостью;
- Steal — перенос слоёв и стилей таблиц из шаблона;
- Global Attribute Extractor — выгрузка атрибутов в Excel (в CSV — штатной командой `DATAEXTRACTION`).
