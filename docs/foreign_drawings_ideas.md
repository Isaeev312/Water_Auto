# Приёмы из зарубежных комплектов чертежей пожаротушения

Источник — три американских комплекта рабочих чертежей водяного пожаротушения из папки `Литература/АУПТ/Пожаротушение/02_1_Нормы_другие`: реконструкция исторического здания суда (RFQ, 2026), библиотека (permit set, 2023), приложение C.19 к делу о преобразовательной подстанции (2022).

Это **не образцы оформления**: они выполнены по NFPA 13 и американской практике, а наши листы оформляются по ГОСТ Р 21.101 и СП 485. Ниже — только отдельные удачные приёмы, которые стоит взять на вооружение, своими словами. Тексты, обозначения и данные этих проектов не копируются. Один комплект помечен как конфиденциальный — из него берутся только идеи.

|---|---|---|---|---|
| 1 | **Табличка гидравлического расчёта прямо на плане:** расчётная площадь, интенсивность, число работающих оросителей, расход, требуемое и имеющееся давление, запас по давлению, наибольшая скорость, учтённые расходы ПК | Блок «Сводка расчёта» на листе плана: S, i, N, Q_р, Q_нас, p_д, P_н, H_н, P_вх, v_max — с пунктами СП 485 | `PlanDxfWriter`, слой ПТ_РАСЧЁТ | **сделано** |

## Чего не переносить

- Интенсивности, площади, расходы ПК, допуски по скорости и шагу — это NFPA 13; у нас только СП 485 (CLAUDE.md: источник чисел — только действующий СП 485).
- Американские обозначения, единицы (дюймы, gpm, psi) и состав штампа.
