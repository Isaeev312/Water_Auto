# Пожаротушение другими ОТВ: разбор норм (31.10.2026)

Источник — СП 485.1311500.2020 с изм. № 1 и № 2, файл `sp-485.1311500.2020-s-izmeneniyami-n-1-2.docx` (реестр, SP485-izm).

## 2. Порошок модульный (разд. 10)

- **Применение (10.1.1–10.1.4).** Пожары классов А, В по ГОСТ 27331 и Е. Запрещено: в помещениях с постоянным
  пребыванием людей и там, откуда люди не успевают выйти до подачи порошка (10.1.3); исключение — Ф5.1 и склады Ф5.2 с
  нагрузкой класса В (прим. к 10.1.3, изм. № 2). Не применяются для веществ, склонных к тлению и самовозгоранию.
  Решение о применении — проектировщика; программа выдаёт замечание, если помещение отмечено как с постоянным пребыванием.
- **Способы (10.1.5, 10.2.6–10.2.9).** По всей площади, локально по площади, по всему объёму, локально по объёму.
  Объём — только при негерметичности до 1,5 % (10.2.8) и при объёме помещения не более 400 м³ (10.2.9); иначе по СТО.
  Локально — при скорости воздуха до 2,0 м/с; расчётная зона — площадь +10 % или объём +15 % (10.2.7).
- **Пуск (10.2.4, 10.4.3).** Все модули помещения — в интервале не более 3 с. Задержка выпуска на эвакуацию, отключение
  вентиляции и закрытие клапанов — это сигналы из АПС и команды АППЗ (есть в программе).
- **Запас (10.2.16), резерв (10.2.19).** 100 % модулей наибольшего помещения; резервирование удваивает количество.
- **Объём помещения (10.2.5).** Оборудование не вычитается, вычитаются сплошные строительные элементы (колонны, балки).

## 3. Количество модулей (прил. И)

```
по объёму   N = Vп / Vн · k1 · k2 · k3 · k4      (И.1)
по площади  N = Sу / Sн · k1 · k2 · k3 · k4      (И.3)
            k4 = 1 + 10·f                         (И.2)
```

- `Vн`, `Sн` — объём и площадь, защищаемые одним модулем, **по документации на модуль** (геометрия распыла).
- `k1` — неравномерность распыла 1…1,2; на максимальной высоте насадка — 1,2 или по документации.
- `k2` — запас на затенения: по площади 1,2; локально 1,3; **по всему объёму числа в своде нет** — его даёт изготовитель.
- `k3` — эффективность порошка по веществу, табл. И.1 (бензин 1,0/0,9 … изопропанол 1,2/1,1; древесина и резина —
  1,0, для ручного пуска и импульсных модулей — 2,0 и 1,5). Вещества нет в таблице — экспериментально.
- `k4` — негерметичность; `f` — доля постоянно открытых проёмов в общей поверхности помещения; для импульсных модулей —
  по документации.
- Дробное `N` — округление вверх; при двух и более модулях — срабатывание в интервале 10.2.4.

## 4. Что нужно от проектировщика и каталога

- Помещение, способ тушения, класс пожара и горючее вещество (строка табл. И.1), площадь открытых проёмов, наличие людей.
- Каталог модулей: `Vн`, `Sн` и высоты установки по диаграммам распыла, `k1`/`k2`/`k4` из документации, если заданы,
  ранг модельного очага, ток пуска (для АПС), масса, сертификат ТР ЕАЭС 043/2017 (А-12). Числа — только из паспорта.

## 5. Открытые вопросы

- А-17: `k2` по всему объёму и `k1` внутри диапазона 1…1,2 — без паспорта модуля программа их не принимает;
  вещество вне табл. И.1 — `k3` не подставляется.
- Газ (разд. 9, прил. Д, Ж) и аэрозоль — разбор отдельно, до кода.
