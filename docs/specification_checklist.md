# Спецификация ПТ.СО — список приёмки

Цель: спецификация оборудования, изделий и материалов, по которой можно заказывать и монтировать установку и которую можно сдавать в экспертизу.
Каждая строка закрыта одним из трёх способов: **сделано** (с тестом или проверкой отрисовки), **решает пользователь** или **вопрос В-xx** (`open_questions.md`).

Источники оформления:
- ГОСТ 21.110-2013, пп. 4.5–4.11;
- ГОСТ Р 21.101-2020, п. 5.2.3;
- ГОСТ 21.601-2011, п. 9.4 (пересказ: элементы трубопроводов, номенклатуру и количество которых определяет монтажная организация, допускается не включать).

Образец состава — спецификация эталона ИОС2.2, прошедшего экспертизу (`07_Эталонные_примеры/01-21-1542-ИОС2.2.pdf`, листы 50–60).

## Оформление (ГОСТ)

| № | Требование | Источник | Состояние |
|---|---|---|---|
| О-1 | Форма 1, графы 1–9, шапка повторяется на каждом листе | 21.110, 4.2, прил. А | сделано |
| О-2 | Без титульного листа: первый лист — основная надпись по форме 3, последующие — по форме 6 | Р 21.101, 5.2.3; 21.110, 4.11 | сделано, проверено отрисовкой листов 1 и 2 |
| О-3 | Обозначение документа — шифр комплекта и «.СО» | 21.110, 4.10 | сделано (`{шифр}-ПТ.СО`) |
| О-4 | Заголовки разделов — в графе 2, по центру, подчёркнуты, отделены от текста пустой строкой; заголовок не остаётся внизу листа без позиций | 21.110, 4.5 | сделано, проверено отрисовкой |
| О-5 | Внутри разделов — группы, в группе — по возрастанию параметров (тип, DN) | 21.110, 4.6 | сделано |
| О-6 | Масса единицы — где известна; для изделий до 25 кг допускается не указывать | 21.110, 4.7 | сделано (трубы) |
| О-7 | Код продукции — только если он есть в документах на продукцию | 21.110, 4.7 | не заполняется, кодов нет в каталогах |
