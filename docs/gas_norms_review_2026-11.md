# Газовое пожаротушение: разбор норм (01.11.2026)

Источник — СП 485.1311500.2020 с изм. № 1 и № 2, файл `sp-485.1311500.2020-s-izmeneniyami-n-1-2.docx` (реестр, SP485-izm):
разд. 9, прил. Г, Д, Ж. Числа — `data/norms/sp485/clauses_9_gas.json`, `table_G_agents.json`, `table_G_16_17.json`.
Формулы прил. Д и Ж в файле — рисунки, переписаны по изображениям. Порошок и общая схема разделов ОТВ — ветка `norms/sp485-powder`.

## 1. Что программа может посчитать по своду

**Масса ГОТВ (прил. Д)**

```
Д.1  Mг = K1·[Mр + Mтр + Mб·n],  K1 = 1,05
Д.2  Mр = Vр·ρ1·(1 + K2)·Cн / (100 − Cн)            сжиженные газы, кроме CO₂
Д.3  Mр = Vр·ρ1·(1 + K2)·ln(100 / (100 − Cн))       сжатые газы и CO₂
Д.4  ρ1 = ρ0·(T0 / Tм)·K3,  T0 = 293 К,  K3 — табл. Г.17 по высоте над уровнем моря
Д.7  K2 = П·δ·τпод·√H,  П = 0,65 / 0,1 / 0,25 / 0,4 по расположению проёмов
Д.8  δ = ΣFн / Vр
Д.9  Mр(А1) = K4·Mр(н-гептан),  K4 = 1,3 / 2,25 / 1,2
```

- `Cн` и `ρ0` — табл. Г.1–Г.15 по ГОТВ и горючему материалу. Вещества нет в таблице: для не-ЛВЖ и подкласса А2 — как
  н-гептан (прим. 3, 4 к Д.1); иначе МОК по ГОСТ Р 53280.3 × 1,2 (CO₂ — 1,7) — опыт, программа не подставляет.
- `δ` не должен превышать табл. Г.16 по объёму помещения (азот — 0,001 м⁻¹, 9.1.3; подкласс А1 — 0,001 м⁻¹, Д.3).
- **Высота над уровнем моря.** Выше 1000 м масса меньше: 1500 м — 0,885, 2000 м — 0,830 (табл. Г.17). Для объектов КР
  (Бишкек около 800 м, Каракол около 1700 м) высота — исходное данное проекта.

**Проём для сброса давления (прил. Ж)**

```
Ж.1  Fс ≥ Kзап·Kдав·Mр / (0,7·K1·τпод·ρ1) · √(ρв / (7·10⁶·Pа·[((Pпр + Pа)/Pа)^0,2857 − 1])) − ΣF
```

Kзап = 1,2; Kдав = 1 для сжиженных, 2,4 азот, 2,66 аргон, 2,44 «Инерген». В своде они обозначены K2 и K3 — это не те
K2, K3, что в прил. Д. Правая часть ≤ 0 — проём не нужен (9.14.2).

## 2. Что даёт не свод, а изготовитель или проектировщик

- **Гидравлический расчёт** (диаметры, насадки, время подачи `τпод`, давление перед насадком `Pн`) — по методикам изготовителя
  (9.4.2); в своде только прил. Е для CO₂ низкого давления. Без него нет `Mтр` (Д.5, Д.6) и точного `τпод`.
- **Остаток в модуле `Mб`**, вместимость и наполнение модулей (не менее 44 %, 9.6.5) — ТД на модуль.
- **Предельное давление `Pпр`** — по прочности конструкций (ГОСТ Р 12.3.047-2012), задаёт проектировщик (архитектор).
- **Минимальная температура `Tм`**, высота над уровнем моря, площадь и расположение проёмов, наличие людей — исходные данные.

## 3. Требования, которые программа проверяет замечаниями

Задержка выпуска не менее 10 с от включения СОУЭ (9.7.1); все сосуды помещения — за 2 с (9.7.2); время подачи 95 % массы
10 / 15 / 60 с (9.7.4); CO₂ — не более 50 человек и только если люди успевают выйти (9.1.2); модули при −20…50 °С (9.8.4);
насадки не дальше 0,5 м от перекрытия (9.11.3); пуск — на высоте до 1,7 м (9.10.4); резерв или запас 100 % (9.6.2, 9.6.3);
станция — высота 2,5 м, 5…35 °С, двукратный воздухообмен (9.12.2).

## 4. Открытые вопросы

- А-18: без гидравлического расчёта изготовителя `τпод` и `Mтр` неизвестны. Предлагается: `τпод` — нормативное время 9.7.4
  (в запас для K2 и Fс), `Mтр` = 0 с замечанием, `Mб` — из ТД модуля; окончательная масса — после расчёта изготовителя.
