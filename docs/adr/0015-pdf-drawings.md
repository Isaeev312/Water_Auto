# ADR 0015. PDF чертежей без AutoCAD: PDFsharp

Статус: принято (01.11.2026).

## Контекст

Для выдачи в экспертизу нужны PDF всех документов тома (графика — векторная, по одному файлу на документ, с ИУЛ по ГОСТ Р 21.101-2020, прил. Х). Записка и спецификации выгружаются в PDF через Microsoft Word (`WordPdf`), чертежи — только DXF; печатать их приходилось из AutoCAD. В README ранее указывался QuestPDF, но его лицензия бесплатна только при выручке до 1 млн USD.

## Решение

1. PDF-библиотека — **PDFsharp 6** (MIT, сборка `PDFsharp`, без зависимостей от Windows).
2. Чертёж печатается из готового DXF (`DxfPdf` в `WaterAuto.Export`): DXF читается ACadSharp, лист — по рамке на слое `ПТ_ФОРМАТ` (формат А3/А2/А1 и масштаб — по её размеру), линии и текст — векторно, чёрным, толщины — по весам линий DXF. Так PDF совпадает с DXF, который проверяет проектировщик, и не нужна вторая отрисовка каждого листа.
3. Поддерживаются примитивы, которые пишет программа: отрезок, полилиния (с дугами), окружность, дуга, текст, многострочный текст, вставка блока. Остальные пропускаются с сообщением.
4. Шрифт — шрифт проекта, если установлен в системе; иначе Arial с сообщением.

## Последствия

- Чертежи в PDF без AutoCAD, в том числе в CLI.
- Типы линий DXF печатаются штрихами в масштабе листа (масштаб документа × масштаб примитива); оси плана — штрихпунктирная тонкая по ГОСТ 2.303.
- Тома собираются в один PDF по описи `tome.json` с ИУЛ по форме 15 ГОСТ Р 21.101-2020 (прил. Х); контрольная сумма — MD5 (алгоритм согласуется с принимающей стороной, Х.6).
- Обозначения томов пока по рабочей документации (ПТ, ПЗ, АПС); состав и шифры стадии П — отдельная задача.
