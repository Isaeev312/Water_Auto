# ADR 0003. Импорт DWG/DXF: ACadSharp

Статус: принято · 25.10.2026 · этап 2a

## Контекст

Этап 2 начинается с импорта плана этажа из DWG/DXF по соглашению о слоях (README §7, ARCHITECTURE §8). ARCHITECTURE §12 называет ACadSharp, запасной вариант — netDxf. Новая зависимость требует ADR (README §8).

## Решение

- **ACadSharp 3.7.16** (MIT, https://github.com/DomCR/ACadSharp) — в `WaterAuto.Import` (чтение) и `WaterAuto.Export` (запись DXF-наложения, этап 3). Сборка для net8.0 без транзитивных зависимостей (по `.nuspec` из кэша NuGet). Пакет читает и пишет DWG и DXF, поэтому тесты генерируют оба формата в момент запуска и бинарные файлы в репозиторий не кладутся. netDxf DWG не читает.
- **Модель плана** (`FloorPlan`, `Room`, `Column`, `Beam`, `Duct`, `NoSprinklerZone`, `Inlet`, `Polygon`, `PlanPoint`) — в Core, без типов ACadSharp: её использует раскладка в Calc (этап 2b). ID объектов — дескрипторы чертежа (`H` + hex): основа обратного пути CAD → расчёт (ARCHITECTURE, принцип 4).
- **Правила импорта** (`FloorPlanImporter`):
  - **Что читается:** только пространство модели. Имена слоёв сравниваются без учёта регистра. Слой, похожий на `ПТ_…`, но не входящий в соглашение (например, с латинской T), — предупреждение.
  - **Геометрия:**
    - контуры, балки, короба и зоны — замкнутые LWPOLYLINE;
    - дуги (bulge) разбиваются на хорды через 10°;
    - колонны — также окружности (36-угольник, шаг 10°) и блоки: мир = точка вставки + поворот·масштаб·(локальная − базовая точка блока); дуги внутри блока тоже разбиваются;
    - вложенные блоки и массивы MINSERT — ошибка;
    - поворот вставки в API — радианы, в файле DXF (код 50) — градусы; проверено тестом по самому файлу;
    - объекты с нормалью (0, 0, −1) (зеркальные) переводятся из OCS в мировые координаты (ось X противоположна); наклонные нормали — ошибка;
    - ввод — точка или блок.
  - **Ничего не пропускается молча:** любой другой объект на слое `ПТ_…` — ошибка `import.unsupportedEntity` с координатами. Исключение — надписи и размеры на слоях геометрии: предупреждение `import.annotationSkipped`, импорт продолжается (геометрия не теряется).
  - **Имя помещения** — TEXT или MTEXT внутри контура; у MTEXT берётся текст без кодов форматирования.
  - **Замыкание:** полилиния, замкнутая совпадающей последней вершиной без флага «Замкнуто», принимается с замечанием уровня Info.
  - **Единицы:** `$INSUNITS` — мм; без единиц — мм с замечанием; другие единицы — ошибка.
  - **Кириллица:** для файлов R2000–R2004 в кодовой странице 1251 (`$DWGCODEPAGE = ANSI_1251`) регистрируется `CodePagesEncodingProvider`. Есть тест на настоящий cp1251-файл.
- **Проверки README §7** — замечания с координатами (`Issue.Location`); при ошибках импорт не продолжается (план = null):
  - ошибки: незамкнутый, самопересекающийся, вложенный или пересекающийся контур; балка с толщиной 0; объект целиком вне контуров; нет `ПТ_ВВОД`;
  - объект частично вне контура (балка в стене, колонна в стене) — только предупреждение: раскладка обрежет его по контуру;
  - допуск — 1 мм.
