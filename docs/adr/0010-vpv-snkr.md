# ADR 0010. Внутренний противопожарный водопровод по СН КР 40-04:2025

Статус: принято (26.10.2026, решение владельца по В-14).

## Контекст

Объект экзаменационного проекта находится в Кыргызской Республике. АУП рассчитывается по СП 485 (в КР отдельных норм по АУП нет). Для ВПВ в КР действует СН КР 40-04:2025, разд. 7 и прил. Ж. До этого решения единственным источником чисел был СП 485.

СП 485 сам определяет, как АУП совмещается с ВПВ:
- Б.1.3.7 — одна группа насосов допустима, если она даёт сумму потребностей обоих водопроводов (Б.29);
- Б.1.3.8 — механически складывать расходы нельзя; расход каждого ПК — по его месту в совмещённой схеме и не меньше нормы ВПВ;
- Б.1.3.16 — пожарные краны включаются в расчётную сеть АУП;
- Б.1.3.15 — продолжительность работы ВПВ, совмещённого с АУП, равна времени работы АУП (то же в СН КР, 7.13).

## Решение

1. Источник чисел: **АУП — СП 485 с изменениями; ВПВ для объектов в КР — СН КР 40-04:2025** (`data/norms/snkr40_04`). Правило в `CLAUDE.md` уточнено.
2. Число струй и минимальный расход струи — табл. Ж.2 по степени огнестойкости, категории, классу конструктивной пожарной опасности (С0–С3), объёму и высоте здания. Эти признаки — поля проекта. Класс С0–С3 — не то же, что класс К0–К3 из раскладки, и из него не выводится. Табл. Ж.1 (жилые и общественные) в данные пока не занесена.
   Для отапливаемых автостоянок закрытого типа (признак проекта `isParking`) число струй и расход — по п. 6.4 СНиП 21-02-99* (решение владельца 26.10.2026; в РФ СНиП заменён СП 113.13330, для объекта в КР применён по указанию владельца): 0,5–5 тыс. м³ — 2 × 2,5 л/с, свыше 5 тыс. м³ — 2 × 5 л/с.
3. Высота компактной струи — не меньше высоты помещения и минимума п. 7.9. По табл. Ж.3 берётся первая строка с высотой струи не меньше требуемой и расходом ствола не меньше минимального по п. 2 (более длинная струя той же колонки, если расхода не хватает), без интерполяции. Клапан, спрыск и длина рукава — поля проекта; ячейка «--» и расход ствола меньше Ж.2 — замечания.
4. Совмещённый расчёт (Б.1.3.16): пожарные краны — потребители сети с характеристикой K = q / √H по строке Ж.3.
   - До построения ПК в трассе принято: все n кранов диктующей секции присоединены в узле ввода трассы одним трубопроводом, длина, DN и отметка диктующего ПК над осью насоса — поля проекта. Весь расход n·q идёт по этому трубопроводу (строже).
   - Если кранам нужен больший напор в узле, чем спринклерной сети, давление диктующего оросителя поднимается до этого напора, и расходы оросителей пересчитываются. Иначе расход ПК — фактический при давлении узла.
   - Местные потери на трубопроводе ПК — те же 20 % (Б.1.3.13), так как он часть совмещённой сети.
5. Расход насоса — Б.29: max(Q_АУП, Q_норм) + Σq_ПК; давление — Б.30 при этом расходе.

## Последствия

- Расход, запас воды и резервуар растут на расход ВПВ.
- В-20 (расход ВПВ для автостоянки) закрыт пунктом 6.4 СНиП 21-02-99*. Размещение ПК в трассе — этап 4.
