# ADR 0011. Кольцевые сети

Статус: принято (26.10.2026; этап 4, В-11 — решение владельца «кольцевые сети нужны»).

## Контекст

СП 485, Б.1.2.16.1: кольцевые схемы (рис. Б.2, секции В и Г) рассчитывают как тупиковые при 50 % расчётного расхода по каждому полукольцу, если нет нормально закрытых разделительных запорных устройств; при их наличии — каждая полуветвь на 100 %. README §5.2 и В-11: решатель сети с кольцами и нормативный вариант, принимается более тяжёлый.

## Решение

1. **Модель трассы.** `PipeRoute` — дерево от ввода (`Segments`) и замыкающие участки колец (`Closures`/`Loops`). Код, которому нужно дерево (путь к диктующему, ограничение ветви, перебор концов ветвей), работает по `Segments`; гидравлика, Б.5, скорости, ведомость, план, аксонометрия и таблица 3 ПЗ учитывают и замыкающие участки.
2. **Трасса кольца** (`design.ring`). Вторая ветвь питающего — у другого конца рядов, достаёт те же ряды; ряд делится по середине между ветвями (рядки остаются тупиковыми). Перемычки — ниже первого и выше последнего ряда по свободным коридорам. Ближняя к вводу перемычка входит в дерево, **дальняя — замыкающий участок**. Если ряды разделены зонами запрета или перемычкам нет места, кольцо не строится (замечание `routing.ringSkipped`), сеть тупиковая. Дополнительные питающие за зонами запрета не закольцовываются.
3. **Решатель** (`LoopSolver`). Узловой метод: неизвестные — пьезометрические давления узлов, уравнения — баланс расходов; трубы ΔP = r·Q·|Q| (Б.6), эмиттеры q = 10·K·√P. Ньютон с демпфированием, линейная система (симметричная положительно определённая) — сопряжёнными градиентами. Проектный режим: давление источника подбирается под p₁ у диктующего (при равных отметках давления пропорциональны давлению источника — одно решение и масштаб; иначе секущие). На тупиковой сети совпадает с `TreeSolver` (тест-ворота).
4. **Нормативный вариант.** Замыкающий участок исключается, на трубах кольца (замыкающий участок и путь по дереву между его концами) потери умножаются на (доля)², доля — 50 % или 100 % (`design.ringValvesClosed`) из записи `sp485.b1_2_16_1.ringShare`. Где резать кольцо — прочтение программы: в наиболее удалённой от ввода части (там, где замыкающий участок).
5. **Выбор.** Принимается вариант с большим давлением в точке подключения; оба значения и принятый вариант — в результате (`RingCheck`) и в ПЗ (формула 5.12).

## Последствия

- Отключение ремонтных участков: для кольцевых **подводящих** трубопроводов п. 6.7.1.42 прямо говорит, что оно в расчёте не учитывается. Для кольцевых питающих — не моделируется; если нужно, решает владелец (В-11).
- Тупиковые сети считаются как раньше.
