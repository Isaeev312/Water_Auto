# ADR 0013. Дорожная карта продукта: все системы безопасности объекта по исходным данным заказчика

Статус: принят (31.10.2026). Цель поставлена владельцем.

## Контекст

Владелец проектирует ВК/НВК и хочет закрывать программой разделы противопожарной защиты и безопасности целиком: получив
реальный объект и ТЗ заказчика, выдавать проект, который можно использовать. Заказчик часто не даёт полных исходных,
поэтому программа должна работать на значениях по умолчанию с явными замечаниями, а решения по нормам фиксировать как
решения проектировщика (ответственность — владелец, вопросы по нормам всё равно записываются в `open_questions.md`).

Сделано на 31.10.2026: АУПТ водяная (ADR 0001–0011), автоматика АУПТ в АПС и АПС паркинга (ADR 0012, этапы 1–2).

## Решение

Разделы продукта и порядок; каждый — свой этап ADR 0012 или новый ADR, своя сборка или папка в `WaterAuto.Alarm`,
нормы — только данные `data/norms/<документ>`, оборудование — каталоги с паспортами и сертификатами (А-12):

1. **АПС** — СП 484: готово для паркинга (прямоугольные и ортогональные помещения, балки, кессоны, ЗКСПС, ИПР, изоляторы,
   АКБ, таблица адресов, спецификация, кабельный журнал, записка). Дальше — стены под углом, несколько этажей, ВРУ на плане.
2. **СОУЭ** — СП 3.13130.2026: способ оповещения (решение проектировщика по СП 3 / Перечню КР), оповещатели звуковые и
   световые по уровню звука (прил. В) и видимости, табло «Выход», линии и АКБ в общий расчёт питания.
3. **АППЗ** (автоматика противодымной защиты и инженерных систем) — СП 7.13130, СП 484 разд. 7: сигналы на отключение
   общеобменной вентиляции, пуск дымоудаления и подпора, клапаны; ТЗ смежному разделу ОВ как сделано для АУПТ.
4. **Пожаротушение другими ОТВ** — СП 485 разд. 7–9: порошковое (модули по площади и объёму), газовое (масса ГОТВ,
   время подачи, сброс давления), ТРВ (тонкораспылённая вода — по ТД модулей); общий каркас — ОТВ как данные каталога,
   расчёт по формулам свода правил, выпуск как у водяной АУПТ.
5. **СКУД, ОС, СВН** — обязательных норм размещения нет (А-09): данные вида `recommendation` и профиль заказчика; выпуск —
   планы расстановки, структурная схема, спецификация, кабельный журнал, ТЗ на электропитание и слаботочные сети.

Разделы выпускаются независимо (31.10.2026): `aupt: false` в проекте — без водяной АУПТ, том АПС строится по приборам АПС; блоки тома АПС в конвейере — общие для обоих случаев. Новые разделы (ОТВ, СКУД…) подключаются так же, без обязательной АУПТ. Общее для всех разделов: одна модель плана (`FloorPlan`), один расчёт электропитания и АКБ (`PowerBudgets`), один
кабельный журнал, одна записка с объяснением шагов (как `aps_pz.docx`), одна спецификация с сертификатами.

## Последствия

- Каждый новый раздел начинается с разбора норм в `docs/*_norms_review_*.md` и записи вопросов; код — после данных.
- Приоритет следующего этапа — СОУЭ и АППЗ: без них раздел АПС паркинга не сдаётся.
- Расширение каталогов оборудования (другие производители, кроме Болид) — отдельными PR по паспортам.
