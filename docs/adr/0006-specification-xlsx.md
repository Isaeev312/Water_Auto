# ADR 0006. Спецификация: ведомость материалов в Calc, xlsx по ГОСТ 21.110 через ClosedXML

Статус: принято · 25.10.2026 · этап 3b

## Контекст

Экзаменационный проект (Маликова 91) требует спецификацию ПТ.СО по форме 1 ГОСТ 21.110 на листе A3. Количества берутся из раскладки и трассы; запас оросителей задан п. 6.1.15. ARCHITECTURE §12 называет для xlsx ClosedXML. Новая зависимость требует ADR.

## Решение

- **Ведомость** — `MaterialTakeoffBuilder` в Calc. Результат — `MaterialTakeoff` в Core, без типов ClosedXML.
  - **Оросители:** установленные и отдельной строкой запас по п. 6.1.15. Пороги 100 и 1000 и количества — в `data/norms/sp485/clauses_6_1.json`.
  - **Трубы:** по DN сортамента (общий с расчётной сетью `PipeSeries`: DN 70 из табл. Б.4 → DN 80 ГОСТ 3262, В-19), длина — сумма участков трассы. Наименование — по табл. Б.2: вид трубы, DN, Ø × стенка.
  - **Фасонные части** — по геометрии трассы:
    - поворот — отвод 90°;
    - два ответвления — тройник, три — крестовина;
    - сужение на прямом продолжении — переход;
    - ороситель в ряду — тройник, в конце ряда — отвод.

    Количество ориентировочное, с примечанием «уточняется при оформлении узлов». Запасов на обрезку и крепления норма не задаёт — их нет.
- **xlsx** — `SpecificationXlsx` в Reports.
  - Графы 1–9 формы 1 с номерами граф.
  - Разделы «Оросители», «Трубопроводы», «Фасонные части»; сквозная нумерация позиций.
  - A3 альбомный, шапка повторяется на каждой странице.
  - Рамку и основную надпись даёт будущий PDF-выпуск (QuestPDF) или проектировщик.
- **ClosedXML 0.105.0** (MIT) — только в `WaterAuto.Reports`. Зависимости (по `.nuspec` из кэша NuGet):
  - DocumentFormat.OpenXml ≥ 3.1.1, ClosedXML.Parser 2.0.0, ExcelNumberFormat 1.1.0, RBush.Signed 4.0.0 — MIT;
  - SixLabors.Fonts 1.0.0 — Apache-2.0;
  - System.Buffers, System.Memory, Microsoft.Bcl.HashCode — MIT.

  Лицензии разрешены README §8.

## Последствия

- Код продукции, поставщик, масса — пустые графы: их заполнит каталог (`data/catalog`) или проектировщик.
- Насос, узел управления, арматура и опоры войдут в ведомость с этапом насоса (3a) и узлов.
- Промывочные заглушки 6.7.1.15 и заглушка у диктующего 6.1.17 — с расчётом диктующей зоны.
