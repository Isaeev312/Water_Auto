# Аналоги Water_Auto

Сравнение с программами расчёта АУПТ — что у них есть, чего нет у нас, и наоборот. Только идеи; код и тексты не копируются.

## «Программа расчёта сети спринклерной установки» (pro-sprinkler.ru)

Источник: https://pro-sprinkler.ru/index.wsgi/programs/sprinkler-network-calculation-program (просмотрено 26.10.2026).

- Гидравлический расчёт распределительной сети по СП 485 с табличным вводом участков; потери — через шероховатость, вязкость и плотность по температуре воды; каталог труб ГОСТ 10704 и ГОСТ 3262.
- Отдельные утилиты: расчёт оросителя (расход, интенсивность, шаг), напор насоса, **потери в узле управления и запорной арматуре по схемам обвязки** с поправкой на угол открытия дискового затвора, **пожарный ствол и рукав** в связанной сети, **диафрагмы**, расстояние до стены при симметричной расстановке.
- Выход: таблица расчёта (.txt, .xlsx), расчёт насоса (.txt, .rtf, .pdf). ПЗ, спецификации, чертежей, кольцевых сетей нет.

**Что взять на вооружение:**
1. Потери в узле управления по паспорту и схеме обвязки — связано с В-02 и В-03 (сейчас узел управления входит в 20 % местных потерь).
2. Подбор диафрагм у ПК при давлении больше 0,4 МПа (сейчас только предупреждение `vpv.diaphragm`): нужна номограмма прил. В СН КР 40-04 или формула диафрагмы.
3. Потери в пожарном рукаве — для проверки напора у ствола (сейчас напор у ПК — по табл. Ж.3, где рукав уже учтён).

**Чего у них нет, а у нас есть:** раскладка по чертежу DWG, трассировка, кольцевые сети, автоподбор оросителя, ВПВ по СН КР, ПЗ по ГОСТ 7.32, спецификация по ГОСТ 21.110, DXF плана и аксонометрии.
