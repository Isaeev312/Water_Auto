# Нормативные числа в текстах C# (ревизия 01.11.2026)

Правило CLAUDE.md: «Нормы — только данные. Ни одного нормативного числа в C#». Поиск по строкам с числом и единицей (м, мм, МПа, л/с, м², дБ, °С, %, см) вне подстановок `{F(...)}`.
